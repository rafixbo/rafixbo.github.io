The problem

Students need practical khatas for SSC and HSC, but ordering them online was messy: guest orders with no accountability, reviews nobody moderated, and a storefront that felt cheap on a phone.

What was built

  • Login-gated ordering — no order without an account; guests are redirected to login with a Bangla message, and the server rejects unauthenticated orders too.
  • Admin control — products, prices, categories, reviews (Pending until admin publishes), FAQ, hero and payments, all from the admin panel.
  • Categories as pills only — no category cards; admin-added categories appear in the pill row above the grid.
  • Mobile-first — full-width search row on phones with a 16px input so iOS Safari never auto-zooms, iOS-style fade transitions, and a clickable whole product card.
  • Loves that survive — saved in the database and in localStorage, healed from the browser copy after a Vercel /tmp reset, and moved to the account at login without double-counting.

The hard part

Two hosts, two truths. Vercel is fast but /tmp is ephemeral, so orders and admin changes can vanish there; alwaysdata is persistent but only 256 MB of RAM, so npm install gets OOM-killed. The fix was a zip that ships pre-installed trimmed node_modules — no install step at all — and a 192 MB heap cap that keeps the shop under the limit.

Outcome

Now live at bestpractical.alwaysdata.net (also on Vercel at kolpocraft-nine.vercel.app), homepage rendering the SSC bundle at ৳1500, with COD ৳60 in Dhaka / ৳120 outside / free over ৳500, and a persistent database on alwaysdata.
