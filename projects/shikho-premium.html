SPOnline Learning Platform

Case study · 2026

Shikho Premium

In production

A full premium learning platform for Bangladesh — a Flutter student app, a NestJS + PostgreSQL backend, a Next.js admin panel, and Bunny.net video, with wallet and manual bKash / Nagad payments.

Year2026
StatusIn production
StackFlutter, NestJS, PostgreSQL, Next.js, Bunny.net, Prisma, Vercel

The problem

Students in Bangladesh buy courses from Facebook pages and Telegram groups, then watch them in unprotected players. Creators lose their videos to downloads within hours, and there is no clean way to sell, manage students, or take bKash / Nagad payments in one place.

What was built

  • Flutter student app — home, My Learning, lecture progress, and native HLS playback with Bunny signed URLs.
  • Secure playback — FLAG_SECURE, no download UI, no MP4 link, short-lived signed HLS only, and a moving watermark showing the student's email running side-to-side across the video.
  • NestJS + PostgreSQL backend — 115 endpoints: auth, courses, lectures, wallet, payment requests, uploads, admin students and app settings.
  • Next.js admin — add courses and lectures, paste a Bunny link per video (with optional Referer / Origin), auto-capture video duration, manage students, wallet and payments.
  • Payments — wallet balance plus manual bKash / Nagad with QR, approved by admin — the way Bangladeshi students actually pay.

The hard part

The hardest part was video security without breaking playback. Bunny has no per-video Origin / Referer — only library-level token auth — so the design had to use signed HLS, short expiry, and a moving email watermark instead. The release build also fought AGP 9: two abandoned plugins had no namespace and one used jcenter(), so one was vendored and patched and the other was removed entirely, with FLAG_SECURE moved into MainActivity.

Outcome

Backend typechecks clean, Vercel production deploy is live at shikho-premium-backend.vercel.app, the release APK is signed with its own keystore, and the admin can publish a course by pasting a Bunny link — no Bunny API keys needed.
