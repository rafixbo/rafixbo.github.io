Online Exam Platform

In production

A Bangla-first exam platform for Bangladeshi students — exam-by-code, 1 mark per correct answer, no negative marking, an admin question bank with JSON import, and a smooth soft UI built to match Progga.

Year2026
StatusIn production
StackTypeScript, Next.js, Prisma

The problem

SSC / HSC students practise from scattered PDFs and coaching sheets, with no timed, exam-like experience in Bangla — and teachers have no simple way to set a paper and hand it to one student.

What was built

  • Exam by code — admin imports a named paper as JSON, assigns it to a student, and the student joins by code. Randomised questions, one attempt, a persisted wall-clock end time, and resume.
  • Fair scoring — 1 point per correct answer, no negative marking, with result, review and history.
  • Admin question bank — JSON import (including a 1,167-question Higher Math bank), papers, and student management.
  • Smooth and soft UI — low-opacity shadows, rounded cards, gentle transitions, 60fps feel, no harsh UI — rebuilt screen by screen to match the reference videos.

The hard part

The UI was corrected repeatedly until it felt right — a clean soft home, Glass / One UI styling in light blue-violet, organised margins, soft navigation, a separate Subjects tab, no gradients, and a working search bar. The MCQ rule also flipped three times before settling on select-once-lock, without showing it as locked.

Outcome

A working web app (v4) with exam-by-code live, an admin panel that matches the app, and a free platform students can actually use for SSC / HSC preparation.
