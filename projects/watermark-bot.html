Watermark Remover Bot

Built

A Telegram bot that removes video watermarks with ffmpeg delogo, a setup wizard, per-position controls and a RAM guard — built for lecture videos.

Year2026
StatusBuilt
StackPython, Telethon, FFmpeg

The problem

Lecture videos carry a channel watermark in the corner. Students want a clean copy, but re-encoding by hand is slow, and auto-detection keeps picking the wrong corner — once, the teacher's face.

What was built

  • Precise delogo — a fixed top-left box (256×39 at 10,7), medium strength, crf 20, after the auto-detector wrongly picked top-right.
  • Owner controls — /setpos TOP_LEFT / TOP_RIGHT / BOTTOM_LEFT / BOTTOM_RIGHT, owner-only, no restart needed.
  • Setup wizard and Bangla guide — so anyone can run it, not just the developer.
  • RAM guard — warn at 512 MB free, critical at 256 MB, clean first, then skip if still low; /ramclean plus a 60-second watchdog.

The hard part

A full 540-second test came out clean: 1280×720, 137 MB down to 108 MB, watermark gone. The remaining limits are honest ones — Telethon MTProto is blocked from this VM, so the bot runs on Windows / VPS, and the 108 MB output stays local because the Bot API caps uploads at 50 MB.

Outcome

A clean 540s re-encode, a measured watermark box, and a bot that knows exactly where the watermark is — and where it isn't.
