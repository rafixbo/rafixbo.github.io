Telegram Stream Bot

Live

A Telegram lecture downloader bot that posts streams into forum topics in a premium decorated style, with RAM auto-clean so it never crashes on overload.

Year2026
StatusLive
StackPython, Pyrogram, Flask

The problem

Lectures arrive as links and files scattered across chats. Teachers need them organised into forum topics, posted beautifully, and delivered without the bot dying halfway through a batch.

What was built

  • Topic-batch uploads — a .txt uploader posts lectures into forum topics, with a Pyrogram + Flask web admin.
  • Premium decoration — every post in a premium layout, every line in glossy animated emojis, with per-line custom emoji IDs from the owner's Premium set.
  • RAM auto-clean — gc plus orphan temp cleanup, a 60-second watchdog, a pre-download check that skips a lecture when free RAM stays below 256 MB after cleaning, and a /ramclean command.
  • Survives overload — thresholds use free MB (warn 512, critical 256), not percent, because percent misleads across VM sizes.

The hard part

MTProto connection timeouts made the bot flap while the web admin still answered 200 — the fix, the watchdog, and the RAM guard were all about making a long-running bot behave on a small, temporary host. Google Cloud Shell sessions end after about an hour of inactivity, so the durable fix is a real VM with systemd.

Outcome

A bot that posts lectures into topics in premium style, cleans up after itself, and keeps going instead of crashing on overload.
